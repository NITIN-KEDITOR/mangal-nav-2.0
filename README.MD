# MANGAL-NAV 2.0 - AI Powered Autonomous Rover Navigation

**NASA Space Apps Challenge 2026 | Team: Lucknow Explorers**

Live Demo: https://NITIN-KEDITOR.github.io/mangal-nav-2.0/

### Problem
Mars rovers need autonomous safe path planning avoiding craters, rocks, slopes using real NASA terrain data.

### Solution
- Real NASA Mars Trek tiles + MOLA elevation simulation
- A* Algorithm O(n log n) with MinHeap for optimal pathfinding
- AI Command Interface: "Go safe", "Avoid craters"
- Jezero Crater (Perseverance landing site) 18.38N, 77.58E
- Battery, elevation, safety calculation

### Tech Stack
HTML5, Leaflet.js, NASA Trek API, A* Algorithm, GitHub Pages

### How to Use
1. Open live link
2. Click 2 points on Mars map
3. AI generates safest path

Built in 48 hours for NASA Space Apps 2026.
